# GLB to DAZ for ComfyUI

**Version 1.0 — November 24, 2026**

A small ComfyUI custom node that uses Blender to convert a textured GLB into an **OBJ, MTL, and separate texture files** for DAZ Studio.

> **Maintenance status:** I am sharing this project as-is and do not plan to maintain it. Please do not expect support, bug fixes, compatibility updates, or pull request reviews. You are welcome to fork it and continue development.

> **AI disclosure:** The code was generated by OpenAI's ChatGPT/Codex. I have read through it myself, but this is not a claim of a comprehensive code review or verification.

## Why I made this

While using an image-to-3D workflow, I ran into distorted textures when downloading/exporting a model through **Save Advanced** in my setup. Importing the saved GLB directly into Blender worked for me, so I made this node to automate that conversion route.

**This is not a criticism of the workflow or its author.** I have not established the cause, and I suspect it is something in my own setup or how I am using it. The workflow author's work made my experiments possible in the first place—thank you!

This is simply the workaround I built for myself and wanted to share in case it helps someone else. It also works with other compatible `FILE_3D_GLB` outputs; it is not tied to one workflow.

## What it does

- Imports the GLB into Blender in the background.
- Extracts embedded textures without intentionally recompressing them.
- Exports a static OBJ with UV coordinates, an MTL file, and separate textures.
- Creates a new numbered folder for each export without overwriting earlier exports.
- Returns the full OBJ path as a `STRING` output.

It does not regenerate UVs or simplify the mesh. No additional pip packages are required.

## Requirements

- ComfyUI and a compatible `FILE_3D_GLB` source node.
- A separate Blender installation with glTF import and the `bpy.ops.wm.obj_export` operator available.
- DAZ Studio to use the exported model.

Blender and DAZ Studio are not bundled. Compatibility with every version or operating system has not been verified.

## Tested environment

- Windows 11
- Blender **5.2.1 LTS**
- DAZ Studio **4.24**

These are the versions used in my setup; other versions have not been verified.

## Installation

### Using Git

With Git installed, open a terminal in your ComfyUI `custom_nodes` directory and run:

```bash
git clone https://github.com/Jan-dash/GLB-to-DAZ-ComfyUI.git
```

This creates `GLB-to-DAZ-ComfyUI` inside `custom_nodes`.

### Manual download

Download the repository ZIP and extract it. Copy the extracted repository folder into `custom_nodes`, optionally renaming it to `GLB-to-DAZ-ComfyUI`.

For either method, the structure should look like this:

```text
ComfyUI/
  custom_nodes/
    GLB-to-DAZ-ComfyUI/
      __init__.py
      convert_glb.py
      README.md
      LICENSE
```

If you installed an earlier copy as `ComfyUI_DAZ_Export`, remove that old installation before installing this copy to avoid loading the same node twice.

### After installation

1. Fully restart ComfyUI.
2. Refresh the browser. If old fields still appear, try **Ctrl+F5**.
3. Add **Export GLB to DAZ (Blender)** from the `3D/DAZ` category.

## Usage

1. Connect a compatible `FILE_3D_GLB` output to `glb`. Your existing GLB save node can remain connected in parallel.
2. Replace `Path to Blender executable` with the full path to your Blender executable. On Windows, use `blender.exe`.
3. Choose a filename prefix and, optionally, an output directory.
4. Run the workflow.
5. Import the resulting `.obj` into DAZ Studio. Keep its `.mtl` and texture files alongside it.

### Node settings

| Input | Default | Description |
| --- | --- | --- |
| `glb` | Connected input | GLB supplied by a compatible source node. |
| `blender_path` | `Path to Blender executable` | Full executable path. On Windows, `blender-launcher.exe` is automatically replaced with `blender.exe`. |
| `filename_prefix` | `daz_export` | Prefix for export folders and OBJ/MTL filenames. |
| `enabled` | `true` | Set to `false` to skip conversion and return an empty path. |
| `output_directory` | Empty | Uses ComfyUI's output directory when empty. Relative paths are resolved inside it; absolute paths are used directly. |
| `timeout_seconds` | `1800` | Maximum Blender runtime: 30 minutes by default. Configurable from 1 second to 24 hours. |

For a subfolder, enter something like `3d/DAZ` in `output_directory`.

### Export files

```text
<output_directory>/
  daz_export_00001/
    daz_export_00001.obj
    daz_export_00001.mtl
    01_<texture-name>.png
    ...
    blender.log
```

Texture names, extensions, and counts depend on the GLB. Folder numbering is independent of other save nodes.

## Limitations and troubleshooting

- **Static geometry:** OBJ does not preserve rigging or animations.
- **Materials:** OBJ/MTL cannot represent every glTF/PBR material feature. Some maps may need manual assignment in DAZ Studio. Packed metallic/roughness channels are not automatically split.
- **Input compatibility:** The GLB must be readable by Blender and contain a mesh. Not every glTF extension is guaranteed to work.
- **Caching:** ComfyUI may reuse results for unchanged inputs. Change the filename prefix or rerun the upstream calculation for a fresh export.
- **Export failures:** Check `blender.log` in the export folder. Exceeding the configured timeout stops Blender and produces a node error.
- **Testing:** The original Blender conversion route worked in my setup. This does not guarantee the same results for every model, material, or software version.
